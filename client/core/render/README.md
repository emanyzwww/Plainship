# core/render - 渲染层

## 定位

使用模板引擎将文档数据与派生数据生成 HTML, 同时处理静态资源, 生成最终页面内容.

## 管线位置

scanner → parser → normalizer → assembly → derive → **render**(本层) → output → distribution

## 职责边界

| 问题                         | 归属            |
|------------------------------|-----------------|
| 文档之间的关系与站点图谱     | core/assembly   |
| 导航 / 分页 / 搜索等派生数据 | core/derive     |
| 最终的 HTML 页面 / 静态资源  | **core/render** |
| 把结果写入输出目录           | core/output     |
