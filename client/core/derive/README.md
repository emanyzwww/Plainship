# core/derive - 功能派生层

## 定位

基于站点图谱, 生成导航、列表、分类、分页、搜索索引等各类派生数据.

## 管线位置

scanner → parser → normalizer → assembly → **derive**(本层) → render → output → distribution

## 职责边界

| 问题                                 | 归属            |
|--------------------------------------|-----------------|
| 文档之间的关系与站点图谱             | core/assembly   |
| 导航 / 列表 / 分类 / 分页 / 搜索索引 | **core/derive** |
| 最终的 HTML 页面                     | core/render     |
